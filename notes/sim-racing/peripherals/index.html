Button Box (按钮盒)

功能与用途

Button Box 是一个外置 USB 控制面板，可扩展额外的按钮、旋钮、开关，用于模拟赛车中的各种功能。

常见功能：

  • 牵引力控制 (TC) 调节
  • 刹车平衡 (BB) 调节
  • 差速器 (Differential) 设置
  • 维修站指令
  • 无线电通讯
  • 雨灯/大灯控制
  • 自定义快捷键
