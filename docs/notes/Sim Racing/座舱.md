## 座舱类型

### 桌面支架 (Desk Stand)

**原理**：固定在桌面上的简易支架。

**优点**：
- 价格便宜
- 便于收纳
- 适合空间有限的用户

**缺点**：
- 稳定性有限
- 不适合直驱基座
- 震动较大

**代表产品**：
- Logitech G Table Mount
- Next Level Racing Wheel Stand
- Wheel Stand Pro

---

### 一体式座舱 (Racing Cockpit)

**原理**：完整的赛车座椅形态，包含方向盘支架、踏板支架、座椅。

**优点**：
- 沉浸感强
- 稳定性好
- 可调节性强

**缺点**：
- 占用空间大
- 价格较高
- 安装较复杂

---

### 铝合金框架座舱 (Aluminum Profile Rig)

**原理**：使用 2020/4040 铝合金型材拼装。

**优点**：
- 完全定制化
- 扩展性强
- 结构稳固
- 可随时调整

**缺点**：
- 需要自行组装
- 需要一定动手能力
- 型材成本

**推荐品牌**：
- Sim-lab
- Trak Racer
-自制（80/20 型材）

---

### 折叠式座舱 (Foldable Cockpit)

**原理**：可折叠收纳的轻量化座舱。

**优点**：
- 便于收纳
- 适合偶尔使用
- 移动方便

**缺点**：
- 稳定性一般
- 承重有限

**代表产品**：
- PlaySeat Challenge
- PlaySeat Evolution
- NLR Wheel Stand 2.0

---

## 座舱结构组件

### 框架

| 类型 | 材料 | 特点 |
|------|------|------|
| 钢管焊接 | 钢 | 结实、稳固 |
| 铝合金 | 铝 | 轻量、可调 |
| 复合材料 | 碳纤维/玻璃钢 | 轻量、高端 |

### 座椅

| 类型 | 特点 | 适用场景 |
|------|------|----------|
| 桶椅 (Bucket Seat) | 赛车专用，侧向支撑好 | 竞速 |
| 休闲椅 | 舒适度优先 | 长时间使用 |
| 电动座椅 | 可调节 | 多用途 |

### 支架

- **方向盘支架**：可调节角度和高度
- **踏板支架**：可调节距离和角度
- **换挡器支架**：可拆卸调节
- **手刹支架**：侧向固定

## 选购要点

### 承重能力

| 基座类型 | 推荐最低承重 |
|----------|-------------|
| 皮带传动 | 15kg+ |
| 中端直驱 | 25kg+ |
| 高端直驱 | 30kg+ |

### 兼容性检查

| 参数 | 说明 |
|------|------|
| 方向盘接口 | 兼容的安装孔位 |
| 踏板尺寸 | 踏板支架间距 |
| 座椅滑轨 | 座椅固定方式 |
| 显示器支架 | VESA 标准 |

### 空间需求

| 座舱类型 | 最小空间需求 |
|----------|-------------|
| 桌面支架 | 1m x 0.5m |
| 折叠座舱 | 1.5m x 1m |
| 一体式座舱 | 2m x 1.5m |
| 专业座舱 | 2.5m x 2m |

## 自制座舱

### 铝合金型材方案

**常用规格**：
- 2020 型材：轻量级应用
- 4040 型材：主力框架
- 4080 型材：高强度需求

**工具清单**：
- 型材切割器
- 内六角扳手
- 角件连接件
- T 型螺母

**参考设计**：
```
     ┌─────────────────────┐
     │      横梁 (4040)     │
     │  ┌───────────────┐  │
     │  │   方向盘支架   │  │
     │  └───────────────┘  │
     │                     │
     │  ┌───────────────┐  │
     │  │    座椅滑轨   │  │
     │  └───────────────┘  │
     │                     │
     │  ┌───────────────┐  │
     │  │   踏板支架    │  │
     │  └───────────────┘  │
     └─────────────────────┘
```

### 焊接钢架方案

**材料**：
- 钢管 (40x40 方管 或 圆管)
- 钢板 (底座连接)
- 座椅滑轨 (二手拆车件)

**步骤**：
1. 绘制设计图
2. 切割钢管
3. 焊接框架
4. 打磨喷漆
5. 安装座椅

## 座舱优化

### 减震处理

- 地板接触点加装橡胶垫
- 框架接触面加垫片
- 座椅底部减震

### 噪声控制

- 金属接触面加垫片
- 紧固件定期检查
- 踏板区域隔音

### 舒适度提升

- 座椅加装缓冲垫
- 头枕和腰部支撑
- 手刹/换挡位置优化

## 安装注意事项

1. **地面平整**：确保放置位置地面平整
2. **螺丝紧固**：定期检查所有连接螺丝
3. **承重分布**：踏板和方向盘重量均匀
4. **线缆管理**：注意电源和数据线布置
5. **空间预留**：留出周边活动空间

## 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 晃动严重 | 安装不稳/螺丝松 | 重新固定/加支撑 |
| 噪音大 | 金属摩擦 | 加垫片/减震 |
| 高度不够 | 支架调节限制 | 改装/更换支架 |
| 踏板打滑 | 地面光滑 | 加防滑垫 |
| 显示器位置不佳 | 支架限制 | 更换显示器支架 |
