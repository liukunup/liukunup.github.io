## 换挡类型

### 序列式换挡 (Sequential)

**原理**：只能向前或向后换挡，每次操作升一挡或降一挡。

**特点**：
- 结构简单
- 换挡速度快
- 操作直观
- 适合拉力、方程式、统一规格赛

**操作方式**：
- 向前推 = 升挡
- 向后拉 = 降挡

---

### H-pattern (手动换挡)

**原理**：模拟真实手动变速箱，7+1/R 的挡位布局。

**特点**：
- 最真实的驾驶体验
- 需要离合配合
- 适合房车赛、GT、经典赛车
- 换挡速度较慢

**操作方式**：
- 推拉结合
- 中间位置 = 空挡
- 不同挡位对应不同位置

---

### 拨片换挡 (Paddle Shift)

**原理**：通过方向盘后方的拨片控制换挡。

**特点**：
- 换挡最快
- 无需松油门
- 双手不离开方向盘
- 适合 GT、方程式

**分类**：
- **单离合拨片**：升挡拨片降挡，升挡需踩离合
- **双离合拨片**：左右各控制离合，换挡更平顺

---

## 离合系统

### 独立离合踏板

与刹车油门分离的第三个踏板：
- 完全模拟真实驾驶
- 需要配合 H-pattern 换挡
- 适合追求真实感的高级玩家

### 序列式离合

- 按键触发离合
- 抬起即松开离合
- 不需要脚操作

### 双离合

- 两个离合踏板
- 模拟 F1 的双离合变速箱
- 升挡无需踩离合

## H-pattern 挡位布局

### 6 速布局

```
     1   3   5
     |   |   |
   ---+---+---+---
     |   |   |
     2   4   6
```

### 7 速布局 (常见于 GT)

```
     1   3   5   7
     |   |   |   |
   ---+---+---+---+---
     |   |   |   |
     2   4   6   R
```

## 传感器类型

### 霍尔传感器 (Hall Effect)

**优点**：
- 无接触磨损
- 精度高
- 寿命长
- 抗干扰

**缺点**：
- 价格较高

### 电位器 (Potentiometer)

**优点**：
- 价格便宜
- 通用性强

**缺点**：
- 有磨损
- 可能产生漂移

## 安装与调试

### 安装注意事项

1. **稳固固定**：换挡器需要牢固安装
2. **挡位校准**：首次使用需校准各挡位位置
3. **H-gate 调节**：部分产品可调节挡位间距
4. **离合设置**：H-pattern 需要正确设置离合

### 软件配置

#### Assetto Corsa

1. `Options` → `Controls`
2. 配置换挡输入
3. 设置挡位数量 (Gears)
4. 校准离合

#### iRacing

1. `Options` → `Controls`
2. 分配换挡键位
3. 选择变速箱类型

## 换挡技巧

### 跟趾动作 (Heel-and-Toe)

在减速降挡时：
1. 用脚尖踩刹车
2. 用脚跟踩油门（保持引擎转速）
3. 同时操作换挡

**目的**：
- 匹配转速
- 平顺降挡
- 防止后轮锁死

### 跟指动作 (Double Clutch)

双踏板离合：

1. 松油门，踩离合
2. 推入空挡
3. 松离合，轰油门
4. 踩离合，推入目标挡
5. 松离合给油

## 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 挡位挂不进去 | 离合未踩/校准问题 | 调整设置/重新校准 |
| 挡位漂移 | 传感器问题 | 重新校准或更换 |
| 换挡不顺滑 | 润滑不足/磨损 | 清洁润滑/检查磨损 |
| 噪音大 | 安装松动/结构问题 | 紧固安装 |
| 换错挡 | 挡位设置问题 | 重新配置 |

---

## 保养建议

- 定期检查螺丝紧固
- 保持换挡机构清洁
- 润滑活动部件
- 检查线缆连接
- 传感器定期校准
