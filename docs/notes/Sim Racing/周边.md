## Button Box (按钮盒)

### 功能与用途

Button Box 是一个外置 USB 控制面板，可扩展额外的按钮、旋钮、开关，用于模拟赛车中的各种功能。

**常见功能**：
- 牵引力控制 (TC) 调节
- 刹车平衡 (BB) 调节
- 差速器 (Differential) 设置
- 维修站指令
- 无线电通讯
- 雨灯/大灯控制
- 自定义快捷键

### 产品推荐

| 品牌 | 特点 | 价格区间 |
|------|------|----------|
| Simucube | 简洁专业 | ¥1000-2000 |
| Traq Racer | 性价比 | ¥500-1000 |
| DIY | 完全自定义 | ¥200-800 |
| 第三方定制 | 木质/铝合金 | ¥800-3000 |

### DIY Button Box

**常用组件**：
- Arduino / Leonardo 开发板
- 按钮/开关
- 旋钮电位器
- 外壳 (3D 打印/激光切割)
- USB 线缆

**软件支持**：
- Joystick Manager
- Arduino Joystick Library
- SimHub
