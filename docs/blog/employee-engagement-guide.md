> 假设你身处一个真实的中层管理或创业团队，团队里有人开始躺平 —— 准时上下班但不主动、推一下动一下、产出质量下滑、责任感淡化。这是一个**系统问题**，需要系统性解决。

## 一、先诊断：为什么会躺平？

治疗前先看病因，常见六类根源：

| 类型 | 典型表现 | 真正的痛点 |
| --- | --- | --- |
| **激励型躺平** | "做了也不涨薪、不升职" | 看不到回报 |
| **疲惫型躺平** | 状态差、效率低、易出错 | 工作量超载或缺乏休息 |
| **迷茫型躺平** | "做这个有什么意义" | 看不到价值/方向 |
| **不公型躺平** | "别人少做我多做" | 觉得分配不均 |
| **能力型躺平** | 推不动、学不会、不敢担责 | 缺技能/怕失败 |
| **文化型躺平** | 团队氛围就这样 | 缺乏标杆与协作张力 |

> **关键**：错误的诊断会导致错误的措施。比如疲惫型员工加 KPI = 加速离职；不公型员工谈理想 = 火上浇油。

## 二、软招：以心换心

> 先用软招，再用硬招。

### 1. 一对一深度沟通

**话术模板（SCQA 模型）**：

> 小张，最近几次的项目里我发现你节奏放缓了（Situation）。我想了解下，是任务难度太大了，还是方向没想清楚（Complication）？我也复盘过自己的工作安排，看看是不是分给你的活儿不合适（Question）。咱们一起聊聊，把阻碍你发挥的因素清一清（Action）。

**关键原则**：
- ✅ 不指责、不下结论
- ✅ 倾听比例 ≥ 70%（你说 30%）
- ✅ 记录对方提到的关键词（"累了""不公平""没意思"）
- ❌ 不要说"你最近怎么了""年轻人不要太计较"

### 2. 让工作"有意义感"

躺平的本质是**意义感缺失**。三种方式重塑意义感：

| 做法 | 操作 |
| --- | --- |
| **看见用户** | 让员工直接接触客户反馈 / 用户故事，而不是只对 KPI |
| **看见影响** | 把"完成任务"翻译成"解决了谁的什么问题" |
| **看见成长** | 给他**有挑战但能胜任**的任务（心流区间） |

### 3. 公平分配 + 透明规则

- **明确每个岗位的"基本动作"清单**（写下来，全员可见）
- **超额贡献 = 公开表彰 + 物质奖励**（双轨）
- **躺平者减少承担核心项目的机会**（温和但明确）
- **绝对不能：让躺平者占便宜，让老实人多干**

> 团队最伤的不是累，而是"干多干少一个样"。一次不公平就能毁掉所有努力的人。

### 4. 给"软"福利

| 软福利 | 成本 | 效果 |
| --- | --- | --- |
| 透明的晋升通道 + 评估标准 | 0 | ⭐⭐⭐⭐⭐ |
| 弹性上下班（结果导向） | 0 | ⭐⭐⭐⭐⭐ |
| 每月 1 天"充电假" | 极低 | ⭐⭐⭐⭐ |
| 学习津贴（书/课/会议） | 低 | ⭐⭐⭐⭐ |
| 季度团队聚餐/活动 | 中 | ⭐⭐⭐⭐ |
| 健康关怀（体检/运动补贴） | 中 | ⭐⭐⭐⭐ |

### 5. 树立标杆（鲶鱼效应）

- 在团队里**公开表扬 1-2 个积极分子**（具体到行为，不是空话）
- 让躺平者看到"奋斗是有回报的"
- 不要让标杆成为"卷王"，避免团队互怼

## 三、硬招：立规矩、明边界、有后果

> **前提**：软招用过且无效 → 才上硬招；硬招不是惩罚，而是**让规则可预期**。

### 1. 设定明确的"基本线"（3 件套）

**① 岗位基本动作清单（BARS）**

把岗位要求拆成 3-5 个**可观察、可测量**的行为指标：

| 岗位 | 基本动作 | 测量方式 |
| --- | --- | --- |
| 工程师 | 每周提交 ≥3 个有效 PR | Git 历史 |
| 产品经理 | 每周完成 1 次需求评审 + 1 份 PRD 更新 | 评审记录 / 文档版本 |
| 测试工程师 | 每周执行 ≥5 个测试用例 + 1 份缺陷报告 | 测试平台 / 缺陷系统 |
| 运营 | 每周完成 1 篇推送 + 1 场活动 | 周报 |
| 销售 | 每月跟进 50 个客户 + 5 个新签 | CRM |

**② 试用期/季度评估标准**
- 软指标（协作、创新、主动性）
- 硬指标（产出、质量、效率）

**③ 公开承诺**

让员工**自己写下**季度目标，签字确认。心理学效应：**承诺一致性原理**。

### 2. PBC + OKR 双轨

- **PBC**（Personal Business Commitment）：硬承诺，必须 100% 完成
- **OKR**（Objectives and Key Results）：挑战性目标，做 0.6-0.7 就合格

这样既保证了底线（PBC），又给了挑战空间（OKR）。

### 3. 设立"后果梯度"

| 阶段 | 时间 | 动作 |
| --- | --- | --- |
| **L1 警示** | 第 1 次发现 | 私下沟通 + 改进计划（书面） |
| **L2 警告** | 1 个月无改善 | 正式书面警告 + 列入观察期 |
| **L3 调岗** | 2 个月无改善 | 调离核心业务 / 降级 |
| **L4 淘汰** | 3 个月无改善 | 协商离职 / 启动辞退流程 |

> **关键**：每一步都要有书面记录，避免日后纠纷。

### 4. 拉开"软差距"

| 行为 | 积极员工 | 躺平员工 |
| --- | --- | --- |
| 奖金系数 | 1.2-1.5 | 0.6-0.8 |
| 年终奖 | 丰厚 | 平均或以下 |
| 培训机会 | 优先 | 暂停 |
| 重点项目 | 主导 | 边缘参与 |
| 晋升 | 加速 | 冻结 |

> 这种**温和但持续的差距**比一次性惩罚更有效。

### 5. 必要的"硬动作"

如果以上全失效：
- **调岗**：给个新环境，看是不是岗位错配
- **降薪**（合规前提下）：最直接但风险大
- **辞退**：最后的手段，但要合法合规（N+1 补偿等）

## 五、避坑指南

### ❌ 不要做的事

| 行为 | 为什么危险 |
| --- | --- |
| 当众批评 / 阴阳怪气 | 激起对立情绪，团队离心 |
| 只看结果不看过程 | 错杀能力型员工 |
| 一碗水端平 | 实际是保护躺平者 |
| 把问题推给 HR | 直属上级才是关键责任人 |
| 给躺平者"新机会" | 机会应该给积极的人 |
| 假装看不见 | 问题会传染，1 个躺平带坏 3 个 |

### ✅ 必须做的事

| 行为 | 为什么有效 |
| --- | --- |
| 区分"疲惫型"和"摆烂型" | 治疗方式完全不同 |
| 给每个员工**定期 1-on-1** | 早发现早干预 |
| 让团队看到"行动 → 结果 → 回报"链条 | 重建因果感 |
| 自己以身作则 | 上梁不正下梁歪 |
| 把规则写在前面 | 让躺平者没话说 |
| 用数据说话 | 避免主观判断 |

## 六、文化建设（治本）

> 短期靠管理，长期靠文化。

| 文化要素 | 落地方式 |
| --- | --- |
| **结果导向** | 不考勤打卡，按交付物评估 |
| **透明信息** | 财务/战略/进度全员可见 |
| **小团队作战** | 3-5 人小组，责任感清晰 |
| **成长可见** | 每个项目后做复盘，让员工看到进步 |
| **拒绝"老好人"管理** | 管理者要敢于做艰难决定 |

## 一句话总结

> **先软后硬、先诊断后开方、先个人后系统、先立标后追责。**
>
> 软招解决"愿不愿意"，硬招解决"敢不敢躺"。
>
> 真正的高手管理者，让躺平的人**自己坐不住**。
