## 各阶段测试活动一览表

| 阶段 | 评审点 | 软件测试 | 硬件测试 | 准出条件 |
|------|--------|----------|----------|----------|
| **概念** | CDCP | 需求评审、可测试性分析 | 需求评审、硬件初评 | 需求可验证 |
| **计划** | TR2/TR3 + **PDCP** | 测试策略、测试计划 | 架构评审、DFx 评审 | PDCP 通过 |
| **开发** | TR4/TR4A | 单元测试、集成测试、SDV | 单板测试、SDV | SDV 通过 |
| **验证** | TR5/TR6 | SIT、系统测试、Beta | SIT、SVT、可靠性、认证 | SVT + TR6 通过 |
| **发布** | ADCP | 验收测试 | 小批量试产 | ADCP 通过 |
| **生命周期** | LDCP | 线上监控、回归测试 | 现场问题处理 | 按需迭代 |

## IPD 测试全景

```
概念 → 计划 → 开发 → 验证 → 发布 → 生命周期
  │       │       │       │       │       │
 CDCP   TR2    TR4    TR5    ADCP   LDCP
        TR3   TR4A   TR6
        PDCP
```

## 测试类型对照

| 测试 | 对象 | 环境 | 目的 |
|------|------|------|------|
| **SDV** | 原型机 | 实验室 | 验证设计规格 |
| **SIT** | 初试产品 | 实验室 | 验证系统集成 |
| **SVT** | 产线抽样 | 产线 | 验证批量一致性 |
| **Beta** | 客户试用 | 客户现场 | 验证用户体验 |

## PDCP 评审要点

| 维度 | 要点 |
|------|------|
| 开发计划可行性 | 产品定义、测试计划、资源分配 |
| 业务潜力 | 财务分析、ROI、优先级 |
| 产品包竞争力 | 客户满意度、竞争优势 |
| 风险管理 | 风险识别、规避计划 |

**决策结果**：Go / Go with Risk / Recycle / Kill

## 四大决策评审点

| 评审点 | 阶段 | 核心问题 |
|--------|------|----------|
| CDCP | 概念末 | 做不做？ |
| PDCP | 计划末 | 怎么做？ |
| ADCP | 验证末 | 能否上市？ |
| LDCP | 生命周期末 | 是否退市？ |

## 关键准出条件

| 阶段 | 准出条件 |
|------|----------|
| 概念 | 需求可验证、无歧义 |
| 计划 | PDCP 通过（TR2/TR3 + 测试计划 + 业务可行） |
| 开发 | SDV 通过、TR4 通过 |
| 验证 | SVT 通过、Beta 通过、TR6 通过 |
| 发布 | ADCP 通过 |
