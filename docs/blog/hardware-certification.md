## 概述

硬件产品要进入市场销售，必须通过相应认证。**认证是按市场切的**，各市场各管各的、基本不通用——国内办完 3C 不等于能直接进欧盟。

## 核心原则

> **卖到哪里，就按哪里的规矩来**

## 全球认证地图

| 维度 | 中国 | 美国 | 欧盟 | 日本 |
|------|------|------|------|------|
| **市场准入** | 3C | UL（多为渠道门槛） | CE（LVD） | PSE |
| **电磁兼容** | 含在相关认证中 | FCC | CE（EMC） | 相关规定 |
| **无线频率** | SRRC | FCC | CE（RED） | 技适/TELEC |
| **有害物质** | 中国 RoHS | 加州 Prop 65 | RoHS、REACH | 相关规定 |
| **报废回收** | 相关规定 | 州级差异 | **WEEE** | 相关规定 |

## 一、中国认证体系

### 1.1 3C 认证（中国强制性产品认证）

**3C**是国家强制性产品认证，落在目录内的产品没有 3C 证书就不能出厂、销售、进口。

**适用产品**：
- 音视频设备
- 信息技术设备
- 电信终端
- 电源适配器
- 锂电池/移动电源（2023/2025 新增）

**认证模式**：
```
类型试验 → 初始工厂检查 → 认证后监督
```

**认证流程**：

```
┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐
│ 申请受理 │ → │ 型式试验 │ → │ 工厂审查 │ → │ 颁发证书 │
└─────────┘    └─────────┘    └─────────┘    └─────────┘
                                                            │
                     ┌─────────────────────────────────────┘
                     ▼
              ┌─────────────┐
              │ 认证后监督  │
              │（年审/抽查）│
              └─────────────┘
```

**现行标准**：
- 安全标准：GB 4943.1-2022
- EMC 标准：GB/T 9254.1-2021

### 1.2 SRRC（无线电发射设备型号核准）

只要产品**主动发射无线电**（WiFi、蓝牙、2.4G 等），就需要 SRRC 认证。

**典型产品**：
- 手机、平板
- 路由器
- 蓝牙耳机/音箱
- 智能手表
- 带无线模块的 IoT 设备

### 1.3 CTA（电信设备进网许可）

带**蜂窝模块**（4G/5G/NB-IoT）的产品需要入网许可。

| 产品类型 | 认证要求 |
|----------|----------|
| 纯 WiFi/蓝牙 | SRRC |
| 带蜂窝（插卡上运营商网络） | SRRC + 入网许可 |

## 二、美国认证体系

### 2.1 FCC（联邦通信委员会）

**FCC 是法律强制的**。任何带数字电路、尤其带无线的电子产品进美国，都绕不开 FCC。

**认证类型**：

| 类型 | 说明 | 适用 |
|------|------|------|
| **FCC SDoC** | 供应商自我声明 | 普通电子设备 |
| **FCC ID** | ID 认证 | 带无线的产品 |

### 2.2 UL 认证

**法律不一定强制，但平台/渠道逼你要。**

- 亚马逊等平台经常要求
- 零售渠道可能要求
- 保险公司可能要求

> UL = "法律不逼你，但不做就上不了架"

### 2.3 加州 Prop 65

美国各州有自己的规矩，**加州 Prop 65** 对某些化学物质有警示标识要求，卖加州要注意。

## 三、欧盟认证体系

**CE 是护照，但它背后挂着一串指令。**

### 3.1 CE 标志

CE 表示产品符合欧盟相关指令的安全、健康、环保要求。

**常见指令**：

| 指令 | 全称 | 适用 |
|------|------|------|
| **RED** | 无线电设备指令 | 带无线的产品 |
| **EMC** | 电磁兼容指令 | 所有电子产品 |
| **LVD** | 低电压指令 | 接入市电的产品 |
| **RoHS** | 有害物质限制 | 电子电气设备 |
| **REACH** | 化学物质注册 | 涉及化学品的产品 |

### 3.2 WEEE（废弃电子电气设备回收）

**欧盟管产品报废之后的回收责任**，这是最容易被忽略的一层。

## 四、日本认证体系

### 4.1 技适/TELEC（无线）

带无线的产品卖日本，需要**技术基准适合证明**。

### 4.2 PSE（电气安全）

带电源、接市电的产品通常需要 PSE 认证。

| 标志 | 类别 | 管控强度 |
|------|------|----------|
| **菱形** | 特定电气用品 | 严格 |
| **圆形** | 非特定电气用品 | 较宽松 |

## 五、消费电子常见认证清单

| 认证 | 地区 | 强制？ | 核心管什么 |
|------|------|--------|------------|
| **3C** | 中国 | ✅ | 安全、EMC |
| **SRRC** | 中国 | ✅ | 无线电频率 |
| **入网许可** | 中国 | ✅（带蜂窝） | 电信准入 |
| **FCC** | 美国 | ✅ | 电磁干扰 |
| **UL** | 美国 | ⚠️（渠道要求） | 安全 |
| **CE** | 欧盟 | ✅ | 多指令组合 |
| **WEEE** | 欧盟 | ✅ | 报废回收 |
| **RoHS** | 欧盟 | ✅ | 有害物质 |
| **PSE** | 日本 | ✅ | 电气安全 |
| **技适** | 日本 | ✅（带无线） | 无线电频率 |

## 六、认证流程概览

### 6.1 3C 认证流程

```
1. 申请受理
   ↓
2. 型式试验（送样到实验室）
   ↓
3. 工厂审查（检查质量体系）
   ↓
4. 颁发证书
   ↓
5. 认证后监督（年审+抽查）
```

**时间**：一般 3-6 个月
**费用**：视产品而定，一般数万至数十万

### 6.2 FCC 认证流程

```
1. 准备技术文件
   ↓
2. 测试（FCC 认可实验室）
   ↓
3. 出具测试报告
   ↓
4. 自我声明 或 申请 FCC ID
   ↓
5. 标注 FCC 标识
```

**时间**：一般 2-4 周
**费用**：视产品而定

### 6.3 CE 认证流程

```
1. 确定适用指令
   ↓
2. 测试（欧盟认可实验室）
   ↓
3. 编制技术文件
   ↓
4. 签署 DoC（符合性声明）
   ↓
5. 加贴 CE 标志
```

**时间**：一般 2-8 周
**费用**：视指令数量而定

## 七、认证避坑指南

### ❌ 常见错误

| 错误 | 后果 |
|------|------|
| 以为 3C 能全球通用 | 无法进入其他市场 |
| 把"不强制"当成"不用做" | UL 被平台卡住 |
| 只看国家层面 | 漏掉加州 Prop 65 等州级要求 |
| 用过时攻略 | 规则更新快，以官方最新为准 |
| 模块过了以为整机免了 | 模块沿用要机构确认 |

### ✅ 正确做法

1. **先确认卖哪些市场** → 再确定要哪些认证
2. **确认产品带不带无线/电池/蜂窝** → 叠加对应认证
3. **找有资质的认证机构确认** → 不要自己推断

## 九、认证 vs 检测 vs 检验

| 概念 | 说明 |
|------|------|
| **认证** | 第三方证明，满足法规要求，颁发证书 |
| **检测** | 测试产品是否符合标准，出具报告 |
| **检验** | 验证产品与标准的符合性 |

> 检测是认证的依据，检验是认证的手段

## 总结

| 市场 | 核心认证 | 带无线的额外认证 |
|------|----------|------------------|
| 中国 | 3C | + SRRC（+ 入网许可） |
| 美国 | FCC | + FCC ID |
| 欧盟 | CE | + RED + WEEE |
| 日本 | PSE | + 技适 |

**记住**：认证是按市场切的，每开一个市场就是一套新的评估。
