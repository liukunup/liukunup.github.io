## 概述

硬件产品全球化销售面临越来越严格的环保要求。本文档梳理各主要市场的环保法规，帮助企业了解合规要点。

## 全球环保法规地图

| 市场 | 法规 | 核心管控 |
|------|------|----------|
| **欧盟** | RoHS / REACH / WEEE | 有害物质 / 化学品 / 回收 |
| **美国** | TSCA / 加州 65 / Prop 65 | 有害物质 |
| **中国** | 中国 RoHS / 消费品指南 | 有害物质 |
| **日本** | JIS 标准 | 有害物质 |
| **全球** | 绿色供应链 | 碳足迹 / ESG |

## 一、欧盟环保法规

### 1.1 RoHS 指令

**RoHS（限制有害物质指令）**是欧盟最核心的环保法规。

**指令全称**：Restriction of Hazardous Substances in Electrical and Electronic Equipment

**当前版本**：RoHS 2.0（2011/65/EU）+ 修订指令 2015/863/EU

**管控物质**：

| 物质 | 限值 | 危害 |
|------|------|------|
| **铅 (Pb)** | 0.1% | 神经毒性 |
| **镉 (Cd)** | 0.01% | 致癌 |
| **汞 (Hg)** | 0.1% | 神经毒性 |
| **六价铬 (Cr⁶⁺)** | 0.1% | 致癌 |
| **多溴联苯 (PBB)** | 0.1% | 干扰内分泌 |
| **多溴二苯醚 (PBDE)** | 0.1% | 干扰内分泌 |
| **邻苯二甲酸二(2-乙基己基)酯 (DEHP)** | 0.1% | 生殖毒性 |
| **邻苯二甲酸丁苄酯 (BBP)** | 0.1% | 生殖毒性 |
| **邻苯二甲酸二丁酯 (DBP)** | 0.1% | 生殖毒性 |
| **邻苯二甲酸二异丁酯 (DIBP)** | 0.1% | 生殖毒性 |

**适用产品**：大型家用电器、小型家用电器、信息技术设备、消费类设备、照明设备、电动工具、玩具等 11 类产品。

**豁免情况**：
- 医用设备（部分豁免）
- 军用设备（豁免）
- 监控设备（部分豁免）
- 特定应用（如铅在玻璃中的应用）

### 1.2 REACH 法规

**REACH（化学品注册、评估、授权和限制法规）**是欧盟关于化学品的综合法规。

**法规全称**：Registration, Evaluation, Authorisation and Restriction of Chemicals

**法规编号**：EC 1907/2006

**核心要求**：

| 要求 | 说明 |
|------|------|
| **注册 (Registration)** | 年产/进口量 ≥1 吨的化学品需注册 |
| **评估 (Evaluation)** | 主管机构评估注册物质 |
| **授权 (Authorisation)** | 高度关注物质 (SVHC) 需授权 |
| **限制 (Restriction)** | 某些物质/产品有限制要求 |

**SVHC（高度关注物质）**：

- 致癌、致突变或生殖毒性 (CMR)
- 持久性、生物累积性和毒性 (PBT)
- 高持久性、高生物累积性 (vPvB)
- 对人体内分泌有严重影响的物质

> 截至目前，SVHC 清单已包含 **240+ 种物质**

**附录 17 限制物质**：

| 物质 | 适用材料 | 限制内容 |
|------|----------|----------|
| 石棉 | 所有材料 | 禁止使用 |
| 镉 | 塑料、油漆、金属 | 有限量要求 |
| 镍释放 | 与皮肤接触的金属 | 限量要求 |
| 偶氮染料 | 纺织品/皮革 | 禁止使用 |
| 多环芳烃 (PAH) | 接触皮肤的塑料/橡胶 | 限量要求 |
| 邻苯二甲酸酯 | 玩具、儿童护理品 | 禁止使用 |

### 1.3 WEEE 指令

**WEEE（废弃电子电气设备指令）**管理电子电气产品的**报废回收责任**。

**指令全称**：Waste Electrical and Electronic Equipment Directive

**核心要求**：

| 要求 | 说明 |
|------|------|
| **回收率** | 需达到一定的回收率目标 |
| **生产者责任** | 生产者需承担回收费用 |
| **标识要求** | 产品需标识回收标志 |
| **注册义务** | 需在各国注册 |

**回收标志**：

```
     ┌─────────────┐
     │             │
     │   ☉ 垃圾桶  │  →  产品需标识此标志
     │   带叉的    │
     │             │
     └─────────────┘
     
含义：不可混入普通垃圾，需单独回收
```

### 1.4 包装指令

**包装指令 (94/62/EC)** 限制包装材料中的有害物质：

| 物质 | 限值 |
|------|------|
| 铅 | ≤100 ppm |
| 镉 | ≤100 ppm |
| 汞 | ≤100 ppm |
| 六价铬 | ≤100 ppm |

## 二、美国环保法规

### 2.1 TSCA 法案

**TSCA（有毒物质控制法案）**是美国的化学品管理法规。

**法案全称**：Toxic Substances Control Act

**管控物质**（2026 年新增）：

| 物质 | 生效时间 |
|------|----------|
| 十溴二苯醚 (DecaBDE) | 已生效 |
| 异丙基化磷酸三苯酯 (PIP 3:1) | 已生效 |
| 六氯丁二烯 (HCBD) | 已生效 |
| 2,4,6-三叔丁基苯酚 (2,4,6-TTBP) | 2026 年 1 月 |
| 五氯苯硫酚 (PCTP) | 2026 年 1 月 |

### 2.2 加州 Prop 65

**加州 65 号提案**要求在加州销售的含有害物质的产品标注警示标识。

**提案全称**：California Proposition 65

**管控物质**：
- 铅
- 镉
- 邻苯二甲酸酯
- 甲醛
- 阻燃剂

**要求**：
- 需标注警告语
- 警告语需包含物质名称
- 适用于多种消费品

### 2.3 CONEG/TPCH

**CONEG/TPCH** 是美国各州通用的包装材料有害物质法规。

**管控物质**：

| 物质 | 限值 |
|------|------|
| 铅 | ≤100 ppm |
| 镉 | ≤100 ppm |
| 汞 | ≤100 ppm |
| 六价铬 | ≤100 ppm |

## 三、中国环保法规

### 3.1 中国 RoHS

**《电器电子产品有害物质限制使用管理办法》**是中国版的 RoHS。

**管理办法**：
- 限量标准：GB/T 26572
- 检测方法：GB/T 26125

**管控物质**（与欧盟 RoHS 一致）：

| 物质 | 限值 |
|------|------|
| 铅 (Pb) | 0.1% |
| 镉 (Cd) | 0.01% |
| 汞 (Hg) | 0.1% |
| 六价铬 (Cr⁶⁺) | 0.1% |
| 多溴联苯 (PBB) | 0.1% |
| 多溴二苯醚 (PBDE) | 0.1% |

**合格评定制度**：
- 型式试验
- 自我声明

### 3.2 消费品指南

**《消费品中重点化学物质使用控制指南》**：

**适用范围**：消费品（除食品、药品、化妆品等）

**新增管控物质**：

| 物质 | 限值 |
|------|------|
| DEHP、BBP、DBP、DIBP | 各 ≤0.1% |

## 四、全球环保合规对比

| 法规 | 地区 | 核心物质 | 限值 |
|------|------|----------|------|
| **RoHS** | 欧盟 | Pb, Cd, Hg, Cr⁶⁺, PBB, PBDE, 邻苯 | 0.1%/0.01% |
| **REACH** | 欧盟 | SVHC (240+物质) | 各不同 |
| **中国 RoHS** | 中国 | Pb, Cd, Hg, Cr⁶⁺, PBB, PBDE | 0.1%/0.01% |
| **TSCA** | 美国 | 十溴二苯醚, PIP(3:1) 等 | 各不同 |
| **Prop 65** | 加州 | Pb, Cd, 邻苯等 | 各不同 |

## 五、环保合规实施

### 5.1 合规流程

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  材料调研   │ → │  供应链管理  │ → │  型式试验   │
└─────────────┘    └─────────────┘    └─────────────┘
                                              │
     ┌───────────────────────────────────────┘
     ▼
┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  出具报告   │ → │  符合性声明  │ → │  标识认证   │
└─────────────┘    └─────────────┘    └─────────────┘
```

### 5.2 供应链管理

**绿色供应链要点**：

| 环节 | 要点 |
|------|------|
| **供应商审核** | 评估供应商环保能力 |
| **材料清单** | 建立物料 BOM 清单 |
| **检测报告** | 收集材料检测报告 |
| **变更管理** | 管控材料变更 |
| **追溯体系** | 建立追溯机制 |

### 5.3 检测项目

| 检测类型 | 检测内容 |
|----------|----------|
| **RoHS 检测** | 铅、镉、汞、六价铬、PBB、PBDE、邻苯 |
| **REACH SVHC** | 高度关注物质筛查 |
| **REACH 附录 17** | 限制物质测试 |
| **包装材料** | 铅、镉、汞、六价铬 |
| **卤素** | 氯、溴（客户要求时） |

## 六、标识与文件要求

### 6.1 RoHS 标识

**CE 标志中的 RoHS**：
- RoHS 合规是 CE 标志的组成部分
- 需签署符合性声明 (DoC)

### 6.2 WEEE 标识

```
产品上需标识：
- 生产者标识
- 回收标志
- 投放市场年份
```

### 6.3 技术文件

| 文件 | 说明 |
|------|------|
| **检测报告** | 第三方实验室出具 |
| **材料清单** | BOM 中标注有害物质 |
| **符合性声明** | 自我声明或第三方声明 |
| **供应商声明** | 原材料供应商声明 |
| **追溯记录** | 保留 10 年 |

## 七、绿色供应链与 ESG

### 7.1 碳足迹

| 概念 | 说明 |
|------|------|
| **碳足迹** | 产品全生命周期的温室气体排放 |
| **范围 1** | 企业直接排放 |
| **范围 2** | 能源间接排放 |
| **范围 3** | 供应链排放 |

### 7.2 ESG 要求

| E (环境) | S (社会) | G (治理) |
|----------|----------|----------|
| 碳排放 | 劳工权益 | 公司治理 |
| 废弃物 | 健康安全 | 信息披露 |
| 水资源 | 社区影响 | 供应链管理 |
| 生物多样性 | 人权 | 合规体系 |

### 7.3 绿色采购

**主流绿色采购标准**：

| 标准 | 说明 |
|------|------|
| **ISO 14001** | 环境管理体系 |
| **ISO 14064** | 碳足迹量化 |
| **IEC QC 080000** | 有害物质过程管理 |
| **EPEAT** | 电子产品环境绩效 |

## 八、常见问题

### Q: RoHS 和 REACH 有什么区别？

| 维度 | RoHS | REACH |
|------|------|-------|
| 性质 | 指令 (Directive) | 法规 (Regulation) |
| 范围 | 电子电气产品 | 化学品/物品 |
| 物质数量 | 10 种 | 240+ SVHC |
| 限制方式 | 禁止使用 | 授权+限制 |

### Q: RoHS 豁免如何申请？

- 准备豁免申请材料
- 提交到欧盟委员会
- 等待评审（通常 12-18 个月）
- 豁免有效期有限，到期需续期

### Q: 供应链环保合规怎么做？

1. 建立供应商环保审核机制
2. 要求供应商提供检测报告
3. 定期抽检关键物料
4. 建立材料变更管控流程

## 总结

| 法规 | 核心要求 | 违规后果 |
|------|----------|----------|
| **RoHS** | 限制有害物质 | 召回/罚款 |
| **REACH** | 化学品注册+SVHC | 召回/罚款 |
| **WEEE** | 回收责任 | 无法销售 |
| **Prop 65** | 警示标识 | 法律诉讼 |
| **中国 RoHS** | 限制有害物质 | 行政处罚 |

**合规要点**：
- 了解目标市场的环保要求
- 建立绿色供应链管理体系
- 定期检测和审核
- 保留完整的合规文件
